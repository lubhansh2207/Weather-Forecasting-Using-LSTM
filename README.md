# Weather Forecasting Using LSTM

A weather forecasting project using Python and Long Short-Term Memory (LSTM) neural networks to explore weather prediction using historical weather data.

## Project Overview

This project demonstrates the use of deep learning for time-series weather forecasting. It includes a Python application, weather data, and supporting HTML templates.

## Technologies Used

- Python
- Streamlit 1.35.0
- TensorFlow 2.15.0
- Pandas 2.2.2
- NumPy 1.26.4
- Matplotlib 3.8.4
- Scikit-learn 1.4.2
- LSTM (Long Short-Term Memory)
- HTML and CSS

## Installation

1. Clone the repository:

```bash
git clone https://github.com/lubhansh2207/Weather-Forecasting-Using-LSTM.git
```

2. Navigate to the project directory:

```bash
cd Weather-Forecasting-Using-LSTM
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
streamlit run app.py
```
